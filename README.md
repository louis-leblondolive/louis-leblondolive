### Highlighted work

**[olive-sh](https://github.com/louis-leblondolive/olive-sh)** - A POSIX-ish shell written in C. FSM based lexer, recursive-descent parser, fork-all-before-wait pipelines and job control. 

**[skiff-http](https://github.com/louis-leblondolive/skiff)** - An HTTP server written in C using an `epoll`/`kqueue` event loop, featuring zero-copy static file serving via `sendfile()`, CGI and keep-alive support.
